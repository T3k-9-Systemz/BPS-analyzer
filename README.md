This is a BPS analyzer for the FIRST Robotics Competition 2026 game Rebuilt. It uses a YOLOv8 AI image recognition model to take a match video from YouTube and analyze the BPS as well as a few other stats of a select bot from that match video.

I unfortunately was unable to complete this project as other things got in the way and the AI model isn't trained. If you do run it, the data of team 5199 (Robot Dolphins From Outer Space) is completely off as I ran a test run of the code with an untrained AI model.
